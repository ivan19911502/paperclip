# Футбольные данные SportPulse

## Когда применять

Используй навык при проектировании схем и API спортивных данных, обработке расписания и результатов, создании demo data или подключении внешнего провайдера.

## Рабочие правила

- Изучи существующие схемы, типы и потребителей данных до изменения модели.
- Представляй отдельно матчи, команды, игроков, лиги, турниры, сезоны, турнирные таблицы, события матча и статистику; фиксируй устойчивые идентификаторы и явные связи.
- Учитывай часовой пояс, время начала, отложенные и прерванные матчи, неизвестный результат, нейтральное поле и незавершённые данные. Не выводи статус матча только из наличия счёта.
- Не смешивай исходные данные провайдера с доменной моделью. Если нужна интеграция, изолируй её адаптером с явным отображением статусов, идентификаторов и временных значений.
- Проектируй обновления так, чтобы повторная доставка не создавала дубликаты и не затирала более свежие данные. Явно отмечай свежесть live-информации.
- Используй реалистичные и внутренне согласованные демонстрационные данные; не представляй их как актуальные реальные результаты.
- Валидируй неполные или некорректные ответы источника и сохраняй понятное поведение при недоступности API или отсутствии ключа.
- Покрывай преобразования и граничные состояния тестами, когда инфраструктура проекта это позволяет.

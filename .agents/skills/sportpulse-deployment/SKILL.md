# Развёртывание SportPulse

## Когда применять

Используй навык при изменении Dockerfile, Docker Compose, конфигурации окружения, health checks, хранения данных или инструкций запуска.

## Рабочие правила

- Сначала изучи существующие контейнеры, порты, скрипты и документацию запуска; сохраняй совместимость с текущей средой.
- Делай сборку и запуск воспроизводимыми. Фиксируй необходимые версии и описывай обязательные настройки без публикации секретов.
- Храни пароли и ключи вне репозитория; предоставляй безопасные примеры env-файлов с фиктивными значениями.
- Настрой health checks с осмысленной проверкой готовности, особенно для PostgreSQL и зависимых сервисов.
- Используй persistent volumes для данных БД и документируй резервное копирование/восстановление, если задача затрагивает эксплуатацию данных.
- Открывай сервисы в LAN только когда это требуется; не выставляй БД и административные интерфейсы наружу без необходимости и защиты.
- Диагностируй запуск по логам, состоянию сервисов и доступности endpoint. Не объявляй сервис готовым лишь потому, что контейнер запущен.
- Проверяй конфигурацию доступными средствами проекта и явно указывай, какие шаги развертывания проверены.
